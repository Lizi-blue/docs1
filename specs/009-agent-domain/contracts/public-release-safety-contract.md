# 契约：公开发布安全

**适用**：本仓全部会同步到公开托管平台的内容（文档、规格、schema、根文件、图解产物）。

## 禁写清单

| 类别 | 示例形态 | 处理 |
|---|---|---|
| 内网域名与主机名 | 内部站点域名、内部代码托管主机 | 删除或替换为占位符 |
| 私有地址 | 私有网段地址与端口 | 删除或替换为占位符 |
| 内网仓库路径 | 仅内网可访问的仓库路径 | 改为公开描述（如「一个内部服务仓」） |
| 凭据与令牌 | 口令、令牌、密钥、授权头 | 一律不得出现；改为占位符或从环境注入 |
| 内部专有细节 | 集群规模、节点信息、部署拓扑、内部工单号 | 抽象为能力类别 |

## 规则

1. 内容 MUST 以「公开发布」为默认标准书写。
2. 运维必需文件（流水线配置、部署清单、环境变量文件）MUST NOT 进入公开镜像；
   若必须公开，MUST 先改为占位符。
3. 需要通过门禁扫描方可提交；命中即失败，直到修复或走例外流程。
4. 例外 MUST 记录理由与恢复计划，且 MUST NOT 放宽凭据项。

## 验收

- 扫描对新增内容与仓内公开面 0 命中。
- 公开站点抽查页面无内网链接。
