# 契约：讲页面结构

**适用**：`docs/agent/**` 下每一讲。

## 必需结构

1. 四段式小节（与基准方向同名同序）。
2. 教学要素齐全（与基准方向一致）。
3. 「官方依据与版本差异」：≥2 条官方链接，每条标注适用版本与差异。
4. 面试追问链：3–5 条递进。
5. 术语引用：正文使用的术语 MUST 在领域术语表出现，全站同词同义。

## 规则

1. 讲 MUST 对齐基准方向（后端 Python 域）的命名、层级与写作风格。
2. 讲正文 MUST 按公开发布标准书写：无内网域名、私有地址、内网路径、凭据与内部专有信息。
3. 自建集群经验 MUST 用抽象能力类别表述，MUST NOT 写具体产品版本、拓扑、地址与节点信息。
4. 讲 MUST NOT 新增项目代码；示例可为片段或伪代码，且 MUST 自包含。

## 验收

- 内容门禁 + 导航门禁 + 受控中文门禁全部通过。
- 公网发布后该页可访问，页内无内网链接。
