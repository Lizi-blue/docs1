# 契约：调研条目

**适用**：业界方案调研类内容（框架与运行时、入口与网关、身份与权限、记忆与上下文）。

## 必填字段

| 字段 | 说明 |
|---|---|
| name | 项目或方案名 |
| url | 公开可访问的仓库或官方文档地址 |
| license | 许可证标识（如 MIT／Apache-2.0／AGPL-3.0） |
| activity.lastCommit | 最近提交日期 |
| activity.archived | 是否归档 |
| scenario | 适用场景 |
| cost | 主要代价（复杂度、运维、许可约束等） |
| decision | 采纳／参考／不采纳 |
| reason | 结论理由（不采纳必填） |
| fetchedAt | 数据抓取日期 |
| source | 抓取来源（接口或官方页面） |

## 规则

1. 取数 MUST 走公开来源（原生 HTTPS 请求官方接口或页面）。
2. 热度与活跃度 MUST 标注来源与抓取日期；MUST NOT 出现无来源数字。
3. 每个主题 MUST ≥3 个候选并给对比表与结论。
4. 调研覆盖面 MUST 至少含四类：框架与运行时、入口与网关、身份与权限、上下文与记忆。
5. 数据 MUST 有复核周期（建议 90 天）；过期条目 MUST 重新核实或标注待核实。

## 验收

- 抽查 3 个条目：字段齐全、链接可访问、日期在复核周期内。
- 无来源热度数字 0 处。
