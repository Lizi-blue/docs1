# 契约：领域元数据

**适用**：新增方向 `docs/agent/` 的领域元数据文件。

## 必填字段

| 字段 | 类型 | 约束 |
|---|---|---|
| name | 字符串 | 领域显示名，受控中文 |
| icon | 字符串 | 与既有领域风格一致 |
| order | 整数 | 不与既有领域冲突，排在既有领域之后 |
| description | 字符串 | 一句话定位，受控中文 |
| entry_type | 枚举 | 取既有领域已用值 |

## 规则

1. 新增领域 MUST NOT 修改站点配置；导航与入口由引擎派生（宪法 II）。
2. 字段名与取值 MUST 通过仓库既有元数据 schema 校验。
3. 知识域 MUST 以独立子目录登记；未开写的域 MUST 标大纲态且不建页面。
4. 领域首页 MUST 给出学习路径与术语表小节（可锚点跳转）。

## 验收

- 新增目录后构建成功，导航中自动出现该领域与知识域层级。
- 元数据校验脚本通过，无手工条目清单。
