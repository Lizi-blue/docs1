**Iteration 2（2026-10-18，用户补充需求后）**

用户补充：DSH 只是开发台入口；日历这类服务要有**自己的运行时入口（页面 + 独立地址 + 权限）**，
服务一多需要多个入口与各自的地址、权限管控。据此新增：

- **US6「每个服务一个入口：地址、权限与复用」**：入口表、三类角色、越权拒绝与审计、≤5 步接入、DSH 与入口的分工判据。
- **FR-025…FR-034**：独立地址、角色权限、会话绑定单服务、审计、声明式接入、入口组件复用（宪法 XI）、
  凭据归属、记忆三层（入口会话/服务/平台）、限流熔断、开发台与入口分工。
- **SC-011…SC-015**：入口表覆盖 ≥3 服务、权限矩阵 ≥3 角色 × 3 操作、接入 ≤5 步、组件四件套与对象模型、分工判据唯一解。
- **边界情况新增 4 条**：入口爆炸、双端同时操作、凭据轮换、审计脱敏。
- **FR-024 调整**：本专题交付「入口架构与组件规范」；真实日历/HA 的接入与部署不在本专题。

复查：内容质量 4/4、需求完备 8/8、就绪度 4/4，全部通过；FR 编号连续（FR-001…FR-034），0 个待澄清。

**Iteration 3（2026-10-18，用户澄清仓定位与调研优先级）**

用户澄清两点：① 本仓**只是文档仓**，用于研究可行性与学习，**不需要实际修改项目代码**；
② 该功能要**优先查找 GitHub 等热门项目与业界常用项目**。据此修订：

- 顶部新增 **Repo Positioning**：本仓是文档与可行性研究仓；不修改项目代码、不部署服务；
  产出只有 Markdown 与自包含图解，结论要能指导接入决策。
- 新增 FR 组 **「业界调研与选型」FR-035…FR-043**：先调研业界常用开源项目；每个候选给名称、
  链接、许可证、活跃度、场景与代价；热度数据必须标核实日期与来源；每主题给对比表与
  采纳／参考／不采纳结论；调研覆盖四类（框架与运行时、入口与网关、身份与权限、上下文与记忆）；
  落到本集群现状（已覆盖什么、缺什么、用开源还是自建）；本仓不改被调研项目代码、不实现服务；
  每主题给可行性判断；引用可核验。
- 调整 FR-007/021/022/024/030：示例用于讲原理且不为本仓新增代码；组件落地只给设计规范与验收口径，
  **本仓不实现组件、不新增复用清单条目**；入口方案给设计规范 + 业界对比，不实现组件；范围边界明确
  「接入、部署与代码改动都不在本专题」。
- 新增 SC-016…SC-020：每主题 ≥3 个业界候选对比（含许可证与活跃度）；覆盖面 ≥4 类；
  引用 100% 带来源与核实日期、无来源热度数字 0 处；每主题给可行性判断与「开源／自建」建议；
  本仓新增内容 0 个项目代码文件。
- 边界情况新增 4 条：热度数据会过期（标核实日期与复核周期）、候选许可证不兼容或停更、
  检索受限时必须标「待核实」而不得用记忆充当事实；审计脱敏保留期。

复查：内容质量 4/4、需求完备 8/8、就绪度 4/4 全部通过；FR 连续（FR-001…FR-043）、SC 连续（SC-001…SC-020）。
本轮 web 检索因服务额度不足不可用（未产生检索消耗），因此规格把「联网核实并标注来源」写成实现阶段的硬要求，
未在规格中写任何未核实的星标或下载量数字。

**Iteration 4（2026-10-18，用户补充：原生 HTTP 可取数 / 格式同构 / 公网不泄漏）**

用户补充三点：① 检索额度不足时可用**原生 HTTP** 取数；② 本仓是文档仓，目标是把业界方案与自己的想法
**按既有方向（如 Python）的格式逻辑**生成一份方向文档；③ 本仓会同步到 GitHub，**不得暴露集群内部信息**。据此：

- 新增 **US7**「按既有方向的格式成文，且可直接公开发布」，独立测试为「同构抽查 3 讲 + 泄漏扫描 0 命中」。
- 新增 FR 组 **「公网发布安全」FR-044…FR-049**：禁内网域名/私有地址/主机名/内网端口与内网仓库路径；
  自建集群经验用抽象能力类别表述；禁凭据、令牌、内部账号与内部链接；调研只用公开来源；
  发布前跑泄漏扫描；泛化表述避免可定位到具体组织。
- 新增 FR 组 **「与既有方向同构」FR-050…FR-054**：元数据与目录一致且零配置注册；领域→知识域→讲分层、

- FR-018 改为抽象能力类别（禁写具体产品、版本、拓扑、地址、节点信息）。
- 新增 SC-021…SC-023：泄漏扫描 0 命中；同构抽查一致；调研数据 100% 来自公开来源并标抓取日期。
- 新增边界 4 条：内部信息边界判据、公开仓不能引用内网链接、泛化表述的误读风险、检索受限时的替代路径。

  本仓内容默认公开；既有方向是格式基准。
