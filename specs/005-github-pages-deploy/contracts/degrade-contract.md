# 契约：静态托管降级（degrade-contract）

适用对象：公网静态托管上的交互组件与页面。判据来源：`spec.md` 的 FR-007、FR-012。

## 1. 降级对象与原因

| 组件 | 页面 | 原因 | 范围 |
|---|---|---|---|
| 任务控制台 | `/frontend/components/task-console` | 公网无后端任务服务 | 仅「提交/取消/实时输出」交互不可用 |

内网目标不受影响：服务与前端组件均可用。

## 2. 必须保留（`intact`）

- 组件简介、依赖的知识域与知识点索引、涉及的知识点表格；
- 组合方式图解、核心源码、设计说明与官方依据；
- 复用四件套与「其他项目如何引用」三种方式；
- API 手册、常见误区、面试追问链、与其他组件的关系、下一讲衔接。

## 3. 必须显示（`visibleText`）

- 明确说明服务不可用，并指出原因（静态托管无后端）；
- 说明影响范围（哪些操作不可用）与替代路径（本地起服务或内网地址）；
- MUST NOT 只显示错误码或英文异常文本；
- MUST NOT 出现空白面板或无反馈的禁用按钮（禁用态需带说明）。

## 4. 禁止行为（`forbidden`）

- 白屏或整页未捕获错误；
- 因后端不可用导致正文、索引或图解缺失；
- 站内出现指向内网地址的链接；
- 静默失败（点了没反应且无提示）。

## 5. 校验方式

| 检查 | 方式 |
|---|---|
| 降级提示存在 | 公网页面打开后检查降级提示文案与原因说明 |
| 正文完整 | 抽查页面必需小节齐备（由内容门禁在构建前保证） |
| 无未捕获错误 | 打开页面时浏览器控制台无未捕获错误 |
| 无内网地址 | 产物门禁断言内网地址字符串命中为 0 |
| 交互不可用时有说明 | 提交类控件处于禁用或提示态，且带文案 |

## 6. 与组件页契约的关系

降级说明属于「使用文档」的一部分，MUST NOT 破坏组件页必需章节与顺序
（见 `specs/004-component-hub-console/contracts/component-page-contract.md`）。
